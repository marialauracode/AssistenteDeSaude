## 📂 Sobre o Projeto
O **Assistente de Saúde** é uma aplicação desenvolvida em Python com interface gráfica, criada para praticar a construção de sistemas interativos e o tratamento de informações fornecidas pelo usuário. A aplicação permite registrar dados básicos, selecionar sintomas e apresentar uma classificação etária acompanhada de recomendações.

## 🛠️ Tecnologias utilizadas
* **Python:** Desenvolvimento da aplicação e implementação da lógica;
* **Tkinter:** Criação da interface gráfica e dos elementos interativos.

## 📦 Funcionalidades
* Cadastro de nome e idade;
* Seleção de até três sintomas;
* Opção para informar outros sintomas;
* Classificação automática entre infantil e adulto;
* Exibição dos dados e sintomas selecionados;
* Apresentação de recomendações básicas;
* Orientação para buscar atendimento profissional em casos específicos.
